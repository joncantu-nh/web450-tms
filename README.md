# Task Management System (TMS)

A MEAN stack web application designed to help users
organize projects, manage tasks, and track progress.

Developed as a greenfield project for Bellevue
University's WEB450 course.

## Technology Stack

- MongoDB / Mongoose
- Express.js
- Angular / TypeScript
- Node.js
- OpenAPI 3.1 / Swagger
